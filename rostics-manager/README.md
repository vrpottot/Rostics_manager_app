# Ростикс Менеджер

Мобильное приложение для менеджера ресторана Ростикс. Первая версия — два модуля:

- **Задачи** — список с фильтрами по статусу, приоритет, исполнитель, срок. Тап по кружку меняет статус (открыта → в работе → готово).
- **График смен** — недельный вид, часы за день и за неделю, добавление/редактирование смен.
- **Команда** — справочник сотрудников (нужен для назначения задач и смен).

## Стек

- Expo SDK 57 + React Native + TypeScript
- React Navigation (bottom tabs + native stack)
- Хранение локально в AsyncStorage (`src/store.tsx`). Бэкенда пока нет — данные живут на устройстве.

## Запуск

```bash
npm install
npx expo start
```

Отсканируй QR-код приложением **Expo Go** (Android / iOS) — Mac не нужен.

## Структура

```
App.tsx                 навигация, провайдер данных
src/store.tsx           стор: employees / shifts / tasks + CRUD + persist
src/types.ts            модель данных
src/utils.ts            даты, часы смен, валидация времени
src/components.tsx      Chip, Avatar, FAB, Card, EmptyState
src/screens/            экраны
```
